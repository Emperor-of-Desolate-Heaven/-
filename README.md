# **多人共享记账系统**

## 《软件工程》课程实验

多人共享记账系统支持成员按旅行、合租、家庭等场景模板创建账本，支持收支记录的提交、审核、驳回、修改金额、转让与删除等全生命周期管理，以及多条件查询、收支统计、按模板结算、预算超支报警和操作日志审计，并支持至少 50 人并发操作；只做账本范围内的记账与核算，不实现用户之间的转账支付，不接入真实支付等外部服务。
